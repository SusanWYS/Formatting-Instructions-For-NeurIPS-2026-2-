# Eliciture Interpretation Paper

ACL-format manuscript for the graded causal implication experiments.

## Build

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error acl_latex.tex
```

The current draft contains an Introduction, Methods, and Results corresponding to `updated_rq_report_2026-08-17/report.pdf`. Source sections are under `sections/`, and report figures are under `figures/`.
