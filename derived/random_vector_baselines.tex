\section{Norm-matched random-vector baselines}
\label{app:random-baselines}
For each model, we sample ten isotropic Gaussian directions at the causal CAA's selected layer and rescale each direction to exactly match the learned causal direction's norm. We reuse the same seeded directions for paired-accuracy, the fixed-$|\alpha|=5$ intervention, and naturalistic evaluations; no random direction is selected using test performance. Naturalistic random-direction projections are divided by that model's learned-CAA critical-minus-control training gap, matching the learned-direction calibration.
