\subsection{Measuring Implicit Causal Inference through Model Behaviors}

\textbf{Models.} In this and all of the following experiments, we test Gemma~2 2B/9B \citep{gemma-team-2024-gemma2}, Qwen3 4B/8B \citep{qwen-team-2025-qwen3}, Llama~3.2 3B \citep{meta-2024-llama32}, and Llama~3 8B \citep{dubey-etal-2024-llama3} base checkpoints.

\textbf{Dataset.} We use 150 manually authored pairs of sentences. In each pair, the modifier or relative clause in the critical sentence provides a plausible cause of that outcome based on physical or everyday world knowledge; in the \emph{control} sentence, it provides an incidental detail. The dataset generally follows the format of [person] [modifier content] [outcome]. For example, \emph{The executive who falsified quarterly revenue figures was fired} is paired with \emph{The executive who wore a blue silk tie was fired}. This dataset extends the no-context eliciture paradigm of \citet{pan-kehler-2025-pragmatic}, which tests whether an apparently descriptive modifier is nevertheless understood as an explanation.

\textbf{Yes/No.} We first present the sentences of [person] [modifier content] [outcome] as context and then ask, ``Does [modifier content] explain why [outcome]?'' We compute the probabilities of the complete answers \emph{Yes} and \emph{No}, including capitalization variants, and normalize them to obtain $P(\text{Yes})$.

\textbf{7-point Likert.} We present the tested sentences as context and then ask how strongly the [modifier content] explains the [outcome] on a scale from 1 (definitely not) through 4 (uncertain) to 7 (definitely yes). We compute a probability for each of the seven complete answers and use their probability-weighted mean as the model's rating.

\textbf{Surprisal.} Following \citet{pan-kehler-2025-pragmatic}, we remove the sentence-final period and append \emph{", and I don't know why."} We use the surprisal of this continuation as the score. The intuition is that if the modifier has already supplied an explanation, subsequently claiming \emph{I don't know why} should be less expected and therefore more surprising. 

For all three measures, paired accuracy is the proportion of pairs in which the critical sentence scores strictly above its control; chance is $.5$, ties count as incorrect.

Not all models can faithfully report their implicit causal inference through Yes/No and 7-Point Likert rating, and the performance of such metalinguistic causal inference increases with model size.


\subsection{Identifying Internal Representations of Implicit Causality Inference}

Given that LMs behaviorally demonstrate implicit causal inference, do LMs form internal representations of implicit causality? Specifically, we ask two questions: 

\textit{1) Do model activations distinguish implicit causal relationships from other relations?} If a representation is specific to causality, a causal direction should separate causal pairs well but transfer less reliably to temporal or plausibility pairs. 

\textit{2) If such representations exist, could the representations of cross-sentence implicit causality transfer to within-sentence causality (eliciture)?} Within-sentence causal inferences are less strong and more optional compared to cross-sentence causal inferences. If the representations of implicit causality inference is robutst, it should transfer across syntactic variations.

\textbf{Datasets.} We use three datasets of matched critical/control pairs:

1) \emph{Causal}: This dataset tests whether models represent implicit causal relationships across different sentence structures. We construct the cross-sentence items using the same critical/control logic as the within-sentence eliciture items in Section~3.1, which extend \citet{pan-kehler-2025-pragmatic}. The dataset contains 630 pairs in total. The training set contains 384 cross-sentence pairs, and the in-distribution (ID) test set contains 96 unseen cross-sentence pairs. The out-of-distribution (OOD) test set contains the 150 unseen within-sentence pairs from Section~3.1. Thus, the ID test changes the scenarios, whereas the OOD test also changes the sentence structure. For example, \emph{Anika avoided the Amber Cafe. The Amber Cafe repeatedly mixed up Anika's allergy order} is the critical item; replacing the second sentence with \emph{The Amber Cafe had a copper sign} creates the control.

2) \emph{Temporal}: This dataset tests whether an event is compatible with a typical occasion for a given [person]. We construct it as a non-causal control using the same critical/control format. We use 1,000 pairs in total: 800 for training and 200 for ID testing. For example, the critical item describes a lifeguard getting a sunburn, whereas the control describes a translator getting the same sunburn. This dataset measures occasion compatibility, not temporal order.

3) \emph{Plausibility}: This dataset tests whether models distinguish probable events from physically impossible events. We adapt the probable--impossible pairs from \citet{hu-etal-2025-shades}, following \citet{lepori-etal-2026-fantasy}. The train/dev pair counts are 56 and 14. For example, the critical item describes someone baking a cake in an oven, whereas the control replaces the oven with a freezer.

\textbf{CAA directions.} Contrastive Activation Addition (CAA) represents a relation with a direction in a model's activation space \citep{rimsky-etal-2024-steering}. At each tested layer, we subtract the final-token activation of every control item from that of its matched critical item, then average these differences over the training pairs. An evaluation item receives a scalar score by projection onto this direction of averaged difference; paired accuracy is the proportion of evaluation pairs for which the critical item scores higher.
