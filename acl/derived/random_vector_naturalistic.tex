\subsection{Naturalistic random-vector baselines}
To test whether the naturalistic projection differences arise along arbitrary
activation-space directions, we repeat the analysis using the ten norm-matched
random directions defined in Appendix~\ref{app:random-baselines}. For each
direction, we subtract the matched non-demographic projection from each
demographic condition and average the difference across the 65 scenarios.
Tables~\ref{tab:random-vector-naturalistic-negative}
and~\ref{tab:random-vector-naturalistic-positive} report the mean and standard
deviation of this value across the ten directions. The random-direction means
remain close to zero across models, conditions, and outcome valences. Thus, the
patterns obtained with the causal direction in
Figures~\ref{fig:naturalistic-aggregate} and~\ref{fig:naturalistic-per-model}
do not follow from projecting the same items onto an arbitrary norm-matched
direction.
